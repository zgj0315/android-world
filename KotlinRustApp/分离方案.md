# 拆分 KotlinRustApp 为 RustLib + KotlinApp 两个独立工程

## Context

原工程 `KotlinRustApp` 将 Rust 代码和 Kotlin 代码混合在同一个 Android 应用工程中，通过 UniFFI 框架实现互调。目标是将其拆分为：
1. **RustLib**：独立的 Android Library 工程，包含 Rust 源码，构建输出 AAR
2. **KotlinApp**：独立的 Android Application 工程，集成 AAR，实现 UI 展示

---

## 工程目录规划

两个新工程与原工程同级：

```
android-world/
├── KotlinRustApp/     # 原工程（参考）
├── RustLib/           # 新工程一：Rust 库
└── KotlinApp/         # 新工程二：Kotlin 应用
```

### 构建 AAR

```bash

./gradlew :rustlib:assembleRelease
# 产物：rustlib/build/outputs/aar/rustlib-release.aar
```

## AAR 传递

将 AAR 复制到 KotlinApp：

```bash
cp RustLib/rustlib/build/outputs/aar/rustlib-release.aar \
   KotlinApp/app/libs/rustlib-release.aar
```

**`KotlinApp/app/src/main/java/org/after90/kotlinapp/MainActivity.kt`**

与原工程基本相同，两处变更：
- 包名：`org.after90.kotlinrustapp` → `org.after90.kotlinapp`
- UniFFI 调用：`uniffi.app.*` → `uniffi.rustlib.*`（对应 Cargo.toml 中 `name = "rustlib"`）

```kotlin
package org.after90.kotlinapp

// ... imports ...

@Composable
fun Greeting(name: String, modifier: Modifier = Modifier) {
    Column(Modifier.safeContentPadding()) {
        Text("Addition using Rust: 2 + 3 = ${uniffi.rustlib.add(2, 3)}")
        val greeting = remember { uniffi.rustlib.Greeter("Hello") }
        Text(greeting.greet("Rust"))
        DisposableEffect(greeting) {
            onDispose { greeting.close() }
        }
    }
}
```

## 关键注意事项

1. **crate name 决定 Kotlin 包名**：`Cargo.toml` 中 `name = "rustlib"` → 生成的绑定包名为 `uniffi.rustlib`
2. **JNA 必须手动声明**：`fileTree` 引用 AAR 时不会读取 AAR 内嵌 POM，需手动加 `net.java.dev.jna:jna:5.14.0@aar`
3. **AAR 包含完整内容**：`dev.gobley.uniffi` 插件会将生成的 Kotlin 绑定打入 `classes.jar`，`.so` 文件打入 `jni/` 目录
4. **library 模块无 applicationId**：`com.android.library` 不需要 `applicationId`、`targetSdk`、`versionCode`

---

## 验证方式

1. 在 `RustLib/` 执行 `./gradlew :rustlib:assembleRelease`，确认 AAR 生成
2. 解压 AAR，确认 `jni/` 下有各 ABI 的 `.so` 文件，`classes.jar` 中有 `uniffi/rustlib/` 包
3. 复制 AAR 到 `KotlinApp/app/libs/`
4. 在 `KotlinApp/` 执行 `./gradlew :app:assembleDebug`，确认编译通过
5. 安装到设备/模拟器，界面显示：
   - `Addition using Rust: 2 + 3 = 5`
   - `Hello, Rust!`
